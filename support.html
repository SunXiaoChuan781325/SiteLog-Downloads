Protect your records

Use Settings → Backup & restore → Export backup regularly. Save the file somewhere you control and check that your chosen provider has finished uploading it. Backups are not encrypted. Restore imports records as new copies and does not overwrite existing projects.

Camera and Photos

Allow camera access in the device's app settings to take photos. If another app is using the camera, pause its video or import a photo instead. For saving to Photos, review the Photos permission. Importing and exporting through a file provider may require its app to finish downloading or uploading.

If something goes wrong

Restart 文杰 Wenjie 工程助手 and try again. If records cannot be opened, keep the app installed and preserve your backups; reinstalling may remove local records. Report your device model, system version, 文杰 Wenjie 工程助手 version, what you expected and the steps that caused the problem. Watermarks and checksums help organise records; they do not establish certified time, location or engineering approval.

Contact support

Use the support website or open an issue at the address below. GitHub may require an account to post. Issues and attachments are public: do not attach private site photos, full backups, addresses, passwords or personal information. Use fictional sample data and remove private details from screenshots.

Resources and icons in Android 1.2.0

The library has 434 resource options across seven groups. Use the red rounded Add action, search by a name or common site term, and select several items before confirming. Resource icons can be changed to one emoji or symbol. Saved project resources remain editable; the library is not an exhaustive global specification or an approved construction plan.

Copy and import a template

Open Export template, review its content, and choose Copy import code or Share import code. A copied confirmation appears only after the clipboard write succeeds. On the receiving device, open Templates → Paste import code, paste the complete code, review the preview and confirm the import. Clipboard access is requested through an explicit action; if it fails, use manual copy/paste or a template file. Large templates can be shared as files.

A code carries readable template definitions, including custom names, without the project's photos and field records. It is not encrypted and is not a cloud download link. Check names before sharing.

Share a complete backup

Use Settings → Share backup file, confirm the content warning and choose an app from the system share sheet. The recipient saves the attached backup file and uses Settings → Restore backup. If a sharing target is unavailable, save the file first and attach it manually. The receiving app may limit attachment sizes; confirm delivery or saving there. WhatsApp and other apps remain separate services.

复制与导入模板

打开“导出模板”，检查内容后选择“复制导入码”或“分享导入码”。只有剪贴板写入成功才提示已经复制。接收者打开“模板 → 粘贴导入码”，粘贴完整代码，预览后确认导入。剪贴板操作由主动点击触发；如果系统拒绝或无法访问，可手动复制粘贴，或改用模板文件。较大的模板请通过文件分享。

导入码包含可读取的模板定义及自定义名称，不包含该工程的照片和现场记录。代码没有加密，也不是云端下载链接，分享前请检查名称。

分享完整备份

在“设置 → 分享备份文件”确认内容提示，再从系统分享面板选择应用。接收者保存附件后，通过“设置 → 恢复备份”导入。找不到目标应用时，可以先保存文件，再到目标应用中手动添加附件。接收应用可能限制文件大小，发送或保存是否完成需在该应用中确认。WhatsApp 等应用由其各自的服务提供方运营。

Recursos e iconos en Android 1.2.0

La biblioteca contiene 434 opciones en siete grupos. Use el botón rojo de añadir, busque por nombre o término habitual y seleccione varios elementos antes de confirmar. Puede cambiar el icono por un emoji o símbolo. Los recursos guardados siguen siendo editables; el catálogo no es una especificación global exhaustiva ni un plan de obra aprobado.

Copiar e importar una plantilla

Abra Exportar plantilla, revise su contenido y elija Copiar código o Compartir código. La confirmación de copia aparece únicamente tras escribir correctamente en el portapapeles. En el dispositivo receptor, abra Plantillas → Pegar código de importación, pegue el código completo, revise la vista previa y confirme. El acceso al portapapeles requiere una acción explícita; si falla, copie o pegue manualmente o use un archivo de plantilla. Las plantillas grandes pueden compartirse como archivos.

El código contiene definiciones y nombres de plantilla legibles, sin las fotos ni los registros de campo del proyecto. No está cifrado ni es un enlace de descarga en la nube. Revise los nombres antes de compartirlo.

Compartir una copia completa

En Ajustes → Compartir copia de seguridad, confirme el aviso y elija una aplicación del menú del sistema. El destinatario guarda el archivo adjunto y usa Ajustes → Restaurar copia. Si no aparece la aplicación deseada, guarde el archivo y adjúntelo manualmente. La aplicación receptora puede limitar el tamaño; compruebe allí el envío o guardado. WhatsApp y otras aplicaciones son servicios independientes.
