TradeDesk · Overview

Operator: Wenjie Lu · Updated 2 October 2026

Local records for everyday trade work

TradeDesk brings customers, sites, jobs, quotes, estimates, appointments, labor, materials, invoices and manually recorded payments into one local workspace. The interface supports English, Simplified Chinese and Spanish. The iOS edition is in release preparation; this page is not a download or approval notice.

Photos, documents and return visits

Keep selected site photos, short videos, supplier documents, checklists and return visits with the relevant job. Create PDFs, export CSV summaries and save JSON backups through iOS file interfaces. Attachments are limited to 8 MiB each and 40 MiB in total.

One device, one set of records

Version 1.0 has no account system, developer cloud, automatic sync, real-time team collaboration or online payment processing. Exchange records manually using a backup. Save a verified backup before deleting the app.

TradeDesk · 产品介绍

运营者：Wenjie Lu · 更新：2026 年 10 月 2 日

把日常工程业务放在一起

TradeDesk 在本机管理客户、现场、工单、报价、估价、排期、工时、材料、发票和手动收款记录。界面支持中文、英文和西班牙文。iOS 版正在准备发布；本页不代表已开放下载或已通过审核。

现场资料与回访记录

将选择的现场照片、短视频、供应商文件、检查清单和返工回访保存在对应工单内。通过 iOS 文件界面生成 PDF、导出 CSV 汇总和 JSON 备份。每个附件最多 8 MiB，合计最多 40 MiB。

每台设备的数据独立

1.0 没有账号、开发者云存储、自动同步、团队实时协作或在线收款。可通过备份手动转移记录。删除应用前，请导出并确认备份已经保存。

TradeDesk · Presentación

Responsable: Wenjie Lu · Actualizado el 2 de octubre de 2026

Registros locales para el trabajo diario

TradeDesk reúne clientes, lugares, trabajos, presupuestos, estimaciones, citas, horas, materiales, facturas y pagos registrados manualmente. La interfaz está disponible en español, inglés y chino simplificado. La edición para iOS está en preparación; esta página no anuncia una descarga ni una aprobación.

Archivos y visitas de seguimiento

Guarda fotos seleccionadas, vídeos cortos, documentos de proveedores, listas de comprobación y visitas con su trabajo. Genera PDF, exporta resúmenes CSV y guarda copias JSON mediante las interfaces de archivos de iOS. Se admiten 8 MiB por archivo y 40 MiB en total.

Registros independientes en cada dispositivo

La versión 1.0 no incluye cuentas, nube del desarrollador, sincronización automática, colaboración en tiempo real ni cobros en línea. Transfiere los registros mediante una copia manual. Guarda y comprueba una copia antes de eliminar la aplicación.
